# Anand's Quick Bites

Create a modern, simple, mobile-first online food ordering website for a local Indian snack shop named “Anand Bal Bhandar”.

Main Requirement

The website must have ONLY THREE food items in the menu:

 Bel — ₹20

Mung Vada — ₹15

Samosa — ₹15

Do not add pizza, burger, dosa, drinks, thali, or any other products.

Homepage

Create an attractive local Indian food-shop homepage with:

Shop name: Anand Bal Bhandar

Heading: “गरमागरम नाश्ता, आता ऑनलाइन ऑर्डर करा!”

Short subtitle: “ताजे आणि चविष्ट नाश्त्याचे पदार्थ”

Large food image/hero section

Prominent “Order Now” button

Clean white background with warm Indian food colors

Mobile-first responsive design

Menu Section

Create exactly 3 product cards.

Card 1

Vada Bel

Price: ₹15

Realistic Vada Bel food image

Quantity selector: − 1 +

Add to Cart button

Card 2

Mung Vada

Price: ₹15

Realistic crispy Mung Vada food image

Quantity selector: − 1 +

Add to Cart button

Card 3

Samosa

Price: ₹15

Realistic crispy Indian Samosa food image

Quantity selector: − 1 +

Add to Cart button

Cart

Create a simple cart drawer/page showing:

Selected item

Quantity

Price

Subtotal

Total amount

Increase/decrease quantity

Remove item

Place Order button

Calculate the total automatically.

Example:
Vada Bel × 2 = ₹30
Samosa × 1 = ₹15
Total = ₹45

Customer Order Form

When the customer clicks Place Order, show a simple form:

Customer Name

Mobile Number

Delivery/Pickup Address

Order Items

Total Amount

Optional note

Add a large “Confirm Order” button.

Order Management

After confirming the order:

Generate a unique Order ID.

Show an order confirmation screen.

Display the complete order summary.

Display customer name, phone number, address, items and total.

Save/maintain the order details so the shop owner can view incoming orders.

Create a simple Admin/Owner Orders section where the owner can see:

Order ID

Customer name

Phone number

Address

Ordered items

Quantity

Total price

Order time

Order status

Order status options:
New → Preparing → Ready → Completed

Address

Add a dedicated shop address section.

Use this placeholder until the actual address is provided:

📍 Anand Bal Bhandar
Address: [ADD SHOP ADDRESS HERE]

Also include a Get Directions button.

Design

Use a warm, attractive Indian street-food style.

Use:

Red/orange/yellow food-inspired accents

White cards

Rounded corners

Food photographs

Large readable prices

Large touch-friendly buttons

Clean typography

Subtle animations

The website must look like a genuine local Indian snack shop rather than a large restaurant chain.

Important Restrictions

ONLY 3 products.

Every product price must be ₹15.

Do not add additional menu categories.

Do not add fake reviews.

Do not add unnecessary sections.

Keep the website extremely simple and fast.

Make it work perfectly on mobile phones.

Use realistic food images for Vada Bel, Mung Vada and Samosa.

The cart and order total must work correctly.

Make the order system ready for connecting to WhatsApp/backend/database.

Suggested Navigation

Home | Menu | Cart | Contact

Final CTA

At the bottom:

“आजच ऑर्डर करा – Anand Bal Bhandar”

Button:
“Order Now” if there  vad bel only keep  bel
